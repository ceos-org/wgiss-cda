# Scope

This client partner guide applies to the CEOS WGISS Connected Data Assets. This client partner
guide covers the IDN, CMR and FedEO instances.

The target audience for this document is the community of software developers aiming to develop applications consuming the interfaces provided by the 
CEOS WGISS Connected Data Assets:

* Implementers of STAC API Client applications or scripts consuming the CEOS WGISS Connected Data Assets STAC interfaces.
* Implementers of OpenSearch API Client applications or scripts consuming the CEOS WGISS Connected Data Assets OpenSearch interfaces.
